# 테스트 사이트 (GitHub Pages: https://stdo-hidden.github.io/porong-proto/)

- `index.html` : **횡스크롤 연못 수호 디펜스 프로토 v0.2** (좌 연못 / 우 벌레 둥지, 동료 소환 카드, 박스 그래픽 단일 HTML)
- `pond-v1/index.html` : 이전 세로 풀스크린 연못 수호 프로토 (보관, `/pond-v1/`)
- `tongue-v1/index.html` : 혀 조작감 프로토 (보관, `/tongue-v1/`)
- `form-evo/index.html` : 폼 진화 프로토 (보관, `/form-evo/`)

이 폴더 내용을 porong-proto 사이트 저장소의 루트에 그대로 복사하면 배포됩니다.

## 규칙 요약
- 목표: **적 둥지(우측)를 부수면 클리어**, 연못(좌측) 체력이 0이면 패배. 🛡/⚔ 버튼으로 수비·진군 전환
- 웨이브 사이는 연못 휴식 화면(전경 + 카드·시설), 다음 웨이브는 버튼으로 수동 시작
- 🏡 내 연못(타이틀): 판이 끝날 때마다 쌓이는 🌸꽃잎으로 영구 꾸미기

## 조작
- 하단 카드: 동료 소환 (💧이슬은 시간·처치로 증가). PC 키보드 1~4
- 전장 탭: 그 자리로 혀 타격 (꾹 누르면 느린 자동 반복), 3번째 명중은 강타
- ◀ ▶ : 포롱이 이동 (PC는 A/D·방향키). 적에게 맞으면 3초 기절
- 세로/가로 화면 자동 대응 (가로가 전장이 더 넓음)

테스트용 URL 파라미터: `?w=N`(N번째 웨이브부터), `?dew=N`(시작 이슬), `?seed=N`(시작 🌱), `?comps=support,trap`(처음부터 영입)
플레이 로그는 타이틀의 「플레이 로그 복사」로 복사. 결과 화면에 6문항 설문(5·6번이 이번 검증 포인트).
